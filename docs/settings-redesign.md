# 设置与配置清单（0.8.34）

底部「设置」提供分类入口和已保存配置摘要。十个表单各自维护草稿，统一显式保存；「帮助与关于」提供分主题的操作指引，「管理音频」保留统计与清理操作。

设置页问号与「帮助与关于」共用 `settings-help.js` 中的本地 Markdown：小标题、步骤、列表、重点和示例均按用户的选择与操作编写。帮助弹窗正文独立滚动、关闭按钮保持可见；关闭后回到原草稿。帮助首页按主题折叠，后台更新保留展开状态。固定模型编号、密钥存储实现和算法阈值不再出现在用户帮助中。

## 保存、测试与作用范围

- 没有改动时禁用保存；数值改回原值后取消未保存状态。非模型页可恢复本页默认值，保存后生效。
- 顶部返回、Android 返回和底部导航统一提供保存并离开／放弃修改／继续编辑。保存失败保留草稿，保存期间锁定字段，后台刷新和网络事件不替换正在编辑的表单。
- 测试使用当前地址、协议、模型、密钥及超时，不写入配置或凭据；临时密钥只参与当次请求。修改相关字段后旧测试结果失效，测试失败不会丢弃输入。
- API Key 留空为保留；清除是独立操作，保存后执行。服务地址改变必须填写对应密钥。公开配置和加密凭据全部提交成功才报告保存成功。
- 新书在导入时保存 `voiceDefaults` 独立快照。全局修改不改变旧书；已有角色绑定优先。默认方案仍检查不同 ID 共用样本的声线冲突。
- 删除个人音色时列出全局及书籍默认方案引用；保留失效引用便于修复。后续未绑定主角回到通用匹配，旁白缺失回退白桦，已有章节成品保留。
- 阅读及听书入口复用同一表单，返回保留书籍／章节上下文；批量制作返回保留选章。倍速滑块、播放、暂停与睡眠定时继续即时执行。

## 实现与迁移

- `settings-model.js`：默认值、版本、校验、归一化、页面字段白名单及深拷贝草稿；`settings-ui.js`／`settings-ui.css`：分类、表单、选择弹窗、帮助及离开保护；主应用接入现有路由。
- 持久化 `settingsVersion=3`。旧 `mode=auto` 迁移为三项自动策略，旧手动迁移为三项人工策略；之后各项独立。非枚举旧接口兼容历史调用，新快照不再写入 `mode`。
- `llmRetries`、`ttsRetries` 分别保存 LLM 和 TTS 的追加重试次数。旧 `retries` 同时迁移给两者，已保存的新字段优先；例如旧值 2 迁移为 LLM 2、TTS 2。移除 `qualityAutoRetry`、`qualityConfirmRetry`，不再提供自动／人工处理选项。
- 每句 TTS 的请求异常、可重试的音频异常与拆分片段共用追加重试预算，暂停和重启不重置；明确的手动重新合成／失败任务继续开始新的预算。质量待处理句子不会因普通继续或重新联网而再次调用服务。鉴权、余额或额度不足、参数、内容拒绝和本地保存错误直接转人工；LLM 不在内容拒绝后自动缩批或删除上下文再请求。安全的本地修复与已有成品保护保持有效。
- 顶层 `playbackSpeed` 迁移到 `settings.playbackSpeed` 并删除顶层副本。已有重试、阈值、并发和阅读偏好保持有效值。
- 已使用旧主角识别方案的书继承原固定默认音色；更早的书保留原行为。配置迁移只处理设置和书籍头信息，不加载章节正文。
- `ModelSettings.java` 统一原生模型参数校验；`testModelConfiguration` 使用临时凭据，共用正式网络请求与错误处理。连接和响应超时贯通原生，桥接等待为两项超时之和再加 30 秒。
- `saveModelConfiguration` 与章节保存队列串行，字段提交限于当前页面修改项。原生用加密事务记录及原子清单写入处理失败回滚和中断恢复。
- 沿用应用 ID `com.vocast.app`、签名和 Android Keystore 别名 `vocast-config`。同时修复一处旧 WebView 无法解析的空值赋值语法，保持原逻辑。
